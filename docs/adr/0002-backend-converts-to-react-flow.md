# ADR 0002: React Flow形式への変換をバックエンドで行う

## ステータス

承認済み

## コンテキスト

Codex CLIのJSONLファイルを解析し、フロントエンドでReact Flowを使って可視化する必要がある。
React Flowが要求するノード/エッジ形式のJSONデータをどこで生成するか決定する必要がある。

## 決定

**バックエンド（Go）でReact Flow形式に変換**し、フロントエンドは受け取ったデータをそのまま表示する。

## 理由

### 採用理由

1. **Goによる高速なパース処理**
   - JSONLパース処理はGoの方がNode.jsより高速

2. **フロントエンド処理の簡素化**
   - フロントエンドは表示ロジックに集中できる

### 検討した代替案

| 案 | 内容 | 採用見送りの理由 |
|------|------|------------------|
| 案B | バックエンドはパース済みの構造化データ（TypedRecord配列等）を返し、フロントエンドでReact Flow形式に変換する | フロントエンドの処理が複雑になる、変換処理のコストがフロントエンドで発生する |

## 結果

- バックエンドでFlowGraph（nodes/edges）を生成する
- フロントエンドはAPIレスポンスをそのままReact Flowに渡す
- キャッシュ（`~/.codex-display`）にもReact Flow形式で保存する
