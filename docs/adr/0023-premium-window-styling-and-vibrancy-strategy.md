# ADR 0023: プレミアムなウィンドウ装飾とVibrancy効果の採用

## ステータス

承認済み

## コンテキスト

Codex Session Displayはデスクトップアプリケーションとして、開発者に優れた視覚的体験（プレミアムな質感）を提供しつつ、ダークモード/ライトモードの双方で一貫した操作性を確保する必要がある。

## 決定

1. **OS標準タイトルバーの非表示とカスタムタイトルバーの実装**:
   OS標準のタイトルバーを非表示（Frameless Window）にし、フロントエンド（React）側でOSに合わせたウインドウ操作ボタンおよびドラッグ可能領域（CSSで `--wails-draggable: drag` を指定）を持つカスタムタイトルバーを実装する。
2. **半透明背景効果（Vibrancy/Mica）の有効化**:
   macOS環境ではVibrancy効果（半透明・すりガラス効果）、Windows環境ではMica効果を背景に適用し、サイドバーやメイン画面がOSデスクトップ背景とシームレスに調和するモダンなデザインを実現する。
3. **Wails v2 起動オプションの構成**:
   Goのメインコードにおいて、以下のWailsオプションを設定する。
   - `TitleBar: options.TitleBarHidden` またはプラットフォーム固有オプションでの非表示設定。
   - `WebviewIsTranslucent: true` および `WindowBackgroundIsTranslucent: true` の有効化。
   - Windows向けに `BackdropType: windows.Mica` の指定。

## 理由

1. **プレミアムなデザイン性の確保**:
   OS標準のタイトルバーの境界線を排し、アプリケーションのテーマ（ダーク/ライト）と完全に融合した一体感のあるレイアウトを提供することで、デスクトップアプリならではのプレミアムな第一印象（WOW要素）を創出できる。
2. **操作性と自由度の向上**:
   タイトルバーにアプリケーション独自のステータス表示やボタン（一覧へ戻る等）を自由に配置可能になり、画面スペースを有効活用できる。
3. **OSとの親和性**:
   macOS/Windowsそれぞれの標準的なデザインガイドラインに則った半透明効果を適用することで、プラットフォームごとに最適化された美しいルック＆フィールを実現できる。
