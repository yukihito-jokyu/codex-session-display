# ADR 0001: Wails（デスクトップアプリ）の採用

## ステータス

承認済み

## コンテキスト

Codex CLIのセッションログ（JSONL）は `~/.codex/sessions` にローカル保存される。
開発者がこれらのログを可視化・分析するためのアプリケーションを構築する必要がある。

## 決定

**Wails（Go + React）によるデスクトップアプリケーション**として構築する。

## 理由

### 採用理由

1. **ローカル処理による高速・安全な動作**
   - データがローカル（`~/.codex/sessions`）に存在するため、ローカル処理の方が高速・安全

2. **プライバシー保護**
   - 外部サーバーへのデータ送信を避けるという要件がある

3. **Goによる高速なパース処理**
   - JSONLパース処理はGoの方がNode.jsより高速

4. **デスクトップAPIの必要性**
   - ネイティブのファイル保存ダイアログ等、デスクトップAPIが必要

5. **オフライン環境での動作**
   - オフライン環境でも動作させる必要がある

### 検討した代替案

| 桌 | 採用見送りの理由 |
|------|------------------|
| Webアプリケーション | データのアップロードが必要、プライバシー上の懸念、オフライン動作が困難 |
| CLIツール | 豊富なUI（React Flow等）の実現が困難 |
| VSCode拡張 | VSCodeへの依存が生じる、独立したアプリケーションとしての利用が制限される |
| Electron | JSONLパースのパフォーマンスがGoに劣る |

## 結果

- Wails v3.x + Go 1.23+ + React 19.x の技術スタックを採用
- 単一のネイティブ実行可能ファイル（`.app` / `.exe`）として配布可能
- ランタイム不要で配布先でそのまま実行可能
