# ADR 0005: token_countをバッジとして表示

## ステータス

承認済み

## コンテキスト

`token_count` イベントはセッション中に頻繁に出現し、トークン使用量を記録している。
このイベントをどのように可視化するか決定する必要がある。

`token_count` は `turn_id` フィールドを持たず、出現位置から属するターンを判定する必要があるという特性がある。

## 決定

`token_count` を独立ノードとしてハーネス上に配置せず、**直前のイベントノードに紐付くバッジ**として表示する。

## 理由

### 採用理由

1. **補助情報としての性質**
   - token_countの情報は補助的なものであり、メインフローを邪魔しない

2. **データ構造上の制約**
   - token_countは `turn_id` を持たず、出現位置から属するターンを判定する必要があるため、独立ノードとして扱うのが不自然

3. **アクションとの紐付けの自然さ**
   - トークン情報は「どのアクションで消費されたか」が重要であり、アクションノードとの紐付けが自然

4. **UIの視認性向上**
   - ノード数を増やさず、キャンバスをシンプルに保てる

### 検討した代替案

| 案 | 内容 | 採用見送りの理由 |
|------|------|------------------|
| 案B | token_countを独立ノードとしてハーネス上に配置し、他のノードと同様に扱う | `turn_id` を持たないため独立ノードとして扱うのが不自然、ノード数が増えて視認性が低下 |

## 結果

- `token_count` は直前の非token_countレコードに紐付けられる
- 同一ノードに複数のtoken_countが紐付く場合、バッジに件数を表示（例: 「12.3K ×2」）
- バッジをクリックすると、トークン内訳（input/output/cached/reasoning）を詳細パネルに展開
- 連続するtoken_countの場合、複数が同一レコードに紐付けられることを許容する

## 関連決定

なし
