# ADR 0008: セッション一覧を年→月→日のツリー構造でグループ化

## ステータス

承認済み

## コンテキスト

セッション一覧画面で多数のセッションファイルを表示する必要がある。
Codex CLIは `~/.codex/sessions/YYYY/MM/DD/` というディレクトリ構造でファイルを保存している。

どのようにセッション一覧を表示するか決定する必要がある。

## 決定

セッション一覧を**年→月→日のツリー構造**でグループ化して表示する。

各階層（年/月/日）は折りたたみ可能とする。デフォルトでは最新の年/月/日を展開済みとする。

## 理由

### 採用理由

1. **ファイルシステム構造の反映**
   - Codex CLIが `~/.codex/sessions/YYYY/MM/DD/` というディレクトリ構造でファイルを保存するため、その構造を反映

2. **探索容易性**
   - セッション数が増えた場合、日付による階層表示が最も探索しやすい

3. **ユーザーの使用パターンへの合致**
   - ユーザーの使用パターン（「昨日のセッションを探す」等）に合致している

4. **見やすい整理**
   - 階層を折りたたむことで、多数のセッションを見やすく整理できる

### 検討した代替案

| 案 | 内容 | 採用見送りの理由 |
|------|------|------------------|
| 案B | フラットなリスト（日付降順） | セッション数が増えた場合に探索が困難 |
| 案C | カレンダービュー | 実装が複雑、日付探索には適しているが他の観点（ブランチ等）での探索が困難 |
| 案D | タグ・ブランチでグループ化 | Codex CLIのファイル構造と合致しない |

## 結果

- 年→月→日のツリー構造で表示
- 各階層のヘッダーに含まれるセッション件数を表示
- 最新の年/月/日をデフォルトで展開済みとする

## 関連決定

なし
