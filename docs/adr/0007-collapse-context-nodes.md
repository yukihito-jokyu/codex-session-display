# ADR 0007: コンテキストノードを折りたたみ（デフォルト非表示）

## ステータス

承認済み

## コンテキスト

コンテキストノード（`base_instructions`: ~20K文字、`developer_instructions`: ~8K文字、`user_instructions`: ~4.7K文字）は大量のテキストを含む。

これらをどのように表示するか決定する必要がある。

## 決定

コンテキストノードを**折りたたみ可能**として、**デフォルトは非表示**とする。

クリックでテキスト全文を展開表示できる。

## 理由

### 採用理由

1. **キャンバスの見やすさ**
   - テキスト量が非常に多く（最大20K文字）、常に表示するとキャンバスが見づらくなる

2. **参照時のみの必要性**
   - コンテキスト情報は参照時に確認すれば十分であり、常時表示の必要性が低い

3. **レイアウト計算の単純化**
   - ノードの高さが均一でないと、レイアウト計算が複雑になる

4. **パフォーマンス**
   - 大量のテキストレンダリングを回避

### 検討した代替案

| 案 | 内容 | 採用見送りの理由 |
|------|------|------------------|
| 案B | デフォルトは表示、ユーザーが折りたたみたい場合は折りたたむ | キャンバスが見づらくなる、レイアウト計算が複雑になる、パフォーマンス低下 |
| 案C | 最初は表示し、自動的に折りたたむ（一定時間後） | ユーザー体験が悪化、レイアウト計算が複雑になる |
| 案D | ノードにはサマリーのみ表示し、詳細は常に別パネルで表示 | 別パネルの実装が複雑になる、ノードからの遷移が分かりにくくなる |

## 結果

- コンテキストノードはデフォルトで折りたたまれている
- ノードには「▸ クリックして展開 (~20K)」のようなガイドを表示
- クリックで `fullText` を展開表示
- `textLength` から文字数を表示

## 関連決定

なし
