# codex-session-display

Codex CLIのセッションログを解析・可視化するためのデスクトップアプリケーション。

## 完全オフラインポリシー (セキュリティ & プライバシー保護)

本アプリケーションは、ローカル環境のみで完結して動作するよう設計されています。

- **外部通信の排除**: アプリケーション内部からインターネット上のいかなる外部サーバー（GitHub Releases APIなどを含む）に対しても、自動または非同期の通信リクエストを一切送信しません。
- **アップデート検知機能の非搭載**: 新バージョンの自動チェック機能や自動アップデート機能は搭載していません。
- **手動アップデート**: アプリケーションの更新は、ユーザーが配布元から新しいバイナリ/インストーラーを手動でダウンロードし、再インストールする運用となります。
