# codex-session-display

Codex CLIのセッションログを解析・可視化するためのデスクトップアプリケーション。

## アップデートポリシーと外部通信

本アプリケーションは、原則としてローカル環境でセッションデータを解析・可視化しますが、利便性向上のため、以下の外部通信を行います。

- **アップデート確認と自動更新**:
  - 起動時に GitHub Releases API (`api.github.com`) を呼び出して最新のリリース情報を取得します。
  - 新しいバージョンが検知された場合、ヘッダーにアップデートボタンが表示されます。
  - ユーザーが承認した場合、GitHub (`github.com`) から最新のユニバーサルバイナリ（zip）をダウンロードし、自動的にアプリの上書きと再起動を行います。

---

## リリース運用方法 (Release Workflow)

本アプリケーションのリリースは、GitHub Actions によって完全に自動化されています。

### 1. バージョンの決定とタグの作成
セマンティックバージョニング（`vX.Y.Z`）に従って、新しいリリースタグを決定します。
コード内にバージョン定数を手動で埋め込む必要はありません（ビルド時に `-ldflags` を使用して動的に注入されます）。

### 2. リリースタグのプッシュ
以下のコマンドを実行して、タグを作成・プッシュします。

```bash
# 例: バージョン v1.0.0 をリリースする場合
git tag v1.0.0
git push origin v1.0.0
```

### 3. 自動ビルドと即時公開
タグがプッシュされると、GitHub Actions（`.github/workflows/release.yml`）が起動し、macOS環境上で以下の処理が実行されます。
1. **ユニバーサルバイナリのビルド**: Wails を用いて `darwin/universal`（Apple Silicon & Intel 共通）のバイナリをビルドします。
2. **インストーラーの作成**: `create-dmg` を用いて新規インストール用の `codex-session-display.dmg` を作成します。
3. **アップデート用パッケージの作成**: `.app` ディレクトリを `codex-session-display.zip` として圧縮します。
4. **GitHub Release の即時公開**: タグ名をもとに GitHub Release を自動作成し、上記アセット（`.dmg` および `.zip`）を添付して直ちに公開します。
